# SharePoint Full File Explorer user guide

The explorer shows the SharePoint documents of a record: folders on the left, files on the right. Some options depend on how your administrator set it up, so you may not see all of them.

## Move between folders

- Click a folder in the tree on the left, or open a folder in the file list.
- Use **Filter folder by name** above the tree to find a folder.
- Use the path above the files to go back to a parent folder.

Folders you opened before appear immediately. A small spinner next to the path shows that the content is being refreshed.

## Find a file

1. Type a part of the file name in **Search files**. The current folder is filtered as you type.
2. To search the whole record, select **All folders** and type at least two characters. **All folders** is available for the documents of a record.
3. The results show the folder of each file. To go there, right-click a result and select **Open containing folder**.

The search compares file names, not the content of the files.

## Open, download or share a file

Right-click a file or folder to see its actions. You can also select one item and use **More actions** (…) in the command bar, or use the command bar at the bottom of the preview pane.

| Action | What it does | Available for |
| --- | --- | --- |
| **Open** | Opens the file, or opens the folder here | Files and folders |
| **Open in browser** | Opens the file in a browser tab | Files |
| **Open in desktop app** | Opens the file in the installed app | Word, Excel, PowerPoint, Visio and Project files |
| **Download** | Saves a copy of the file | Files |
| **Copy link** | Copies the SharePoint link | Files and folders |
| **Open in SharePoint** | Opens the folder in SharePoint | Folders |
| **Open containing folder** | Opens the folder of a search result | Search results |

**Open in SharePoint** in the command bar opens the current folder.

## Preview a file

1. Click the **Preview** button on the right side of the command bar. The pane stays open, also for other records, until you close it.
2. Select a file. Word, Excel, PowerPoint and Visio files are shown as documents, which can take a few seconds. Other files are shown as a preview image.

The file actions are in the command bar at the bottom of the pane.

If the preview stays empty, open SharePoint once in the same browser. If that does not help, ask your administrator to check the browser's cookie settings.

## Change how files are shown

- **View type:** use the view menu in the command bar to switch between tiles, list and compact list.
- **Tile size:** the same menu offers small or large tiles.
- **Sort:** use the **Sort** menu to choose a column and the sort direction. It works in all view types.

The browser remembers these choices, along with whether the preview pane is open.

## Upload files

If your administrator enabled it, drag files from your computer onto the file list. They are uploaded to the folder that is currently open, and the folder is refreshed afterwards.

Files that cannot be uploaded, for example because a file with the same name already exists, are listed with the reason. Folders cannot be uploaded.

## Use it on a phone or a narrow form

When the space is narrow, the explorer adapts:

- The **Folders** button opens the folder tree.
- The preview covers the files. Close it to return to the list.
- Commands show icons only. Hover over an icon, where possible, to see its name.
